# Операционные системы

Восемь лабораторных работ и групповой курсовой проект: от модификации ядра Pintos и разработки небольшой ОС до сетевого программирования, многопоточности и исследования безопасности контейнеров.

В разделе собраны отчёты в PDF и DOCX, исходный код и дополнительные материалы. Описания ниже основаны на содержимом отчётов и опубликованных файлов.

**Технологии:** C · C++ · x86 Assembly · Pintos · QEMU · Linux · Windows API · POSIX Threads · TCP/UDP · Docker · BuildKit

## С чего начать

- **[Безопасность контейнеризации](./course-project-containerization-security/report.pdf)** — курсовой проект об архитектуре Docker и двух уязвимостях, связанных с нарушением изоляции.
- **[Разработка CalcOS](./lab-06-operating-system-design-principles/lab-06-operating-system-design-principles.pdf)** — загрузчик, ядро и командный интерфейс учебной ОС для x86.
- **[TCP/UDP](./lab-07-tcp-udp/)** — реализации сетевых клиентов и серверов, скрипты эмуляции и тестовые сообщения.
- **[Многопоточность](./lab-08-multithreading-mechanisms/)** — вычислительные задачи, параллельная сортировка и синхронизация потоков в Windows и Linux.

## Курсовой проект — безопасность контейнеризации

**Эксплуатация уязвимостей механизма контейнеризации серверных приложений**

Групповая учебная работа по архитектуре Docker, отличиям контейнеров от виртуальных машин и условиям нарушения контейнерной изоляции.

В отчёте рассмотрены:

- **CVE-2024-23652:** работа BuildKit с путями и очисткой файлов при сборке образов; приведён учебный сценарий демонстрации.
- **CVE-2022-0492:** механизм `release_agent` в cgroups v1 и условия выхода из контейнера; описан эксперимент с расширенными привилегиями контейнера и отключёнными защитными профилями.
- Подготовка окружения, ход экспериментов, результаты и листинги скриптов в приложениях. Для использованного стороннего PoC приведён источник.

Результаты демонстраций относятся к условиям стенда, описанным в отчёте.

**Материалы:** [Отчёт PDF](./course-project-containerization-security/report.pdf) · [Отчёт DOCX](./course-project-containerization-security/report.docx)

## Формат материалов

Для работ 01–06 реализации и фрагменты кода представлены в отчётах; отдельные исходные проекты в этих папках не опубликованы. Для работ 07–08 исходники размещены в `src/`. Курсовой проект представлен отчётом со скриптами в приложениях.
