# Практика в Digital Security

Отчёт об учебной (ознакомительной) практике по направлению **10.05.03 «Информационная безопасность автоматизированных систем»**, СПбПУ.

**Автор:** Корпусов Дмитрий Николаевич  
**Период:** 24 июня — 7 июля 2026 года  
**Организация по отчёту:** ООО «Диджитал Комплаенс», Санкт-Петербург

Практика посвящена оценке защищённости веб-приложений на учебных стендах **PortSwigger Web Security Academy**. В отчёте собраны теоретические сведения, решения лабораторных заданий, иллюстрации и рекомендации по устранению уязвимостей.

## Направления работы

| Направление | Содержание |
| --- | --- |
| Аутентификация | Перечисление пользователей, защита от перебора, двухфакторная аутентификация и восстановление доступа |
| Контроль доступа | Проверка прав пользователей, горизонтальная и вертикальная эскалация привилегий |
| Бизнес-логика | Анализ доверия к клиентским данным и ошибок в последовательности действий приложения |
| SQL-инъекции | UNION-атаки, извлечение данных, анализ ошибок и слепые SQL-инъекции |
| Межсайтовый скриптинг | Отражённый, хранимый и DOM-based XSS |

## Инструменты и навыки

- Перехват, анализ и изменение HTTP-запросов и ответов.
- Работа с Burp Suite, включая Proxy, Repeater и Intruder.
- Использование Burp Collaborator и учебного Exploit Server в описанных лабораторных сценариях.
- Проверка механизмов аутентификации, авторизации и обработки пользовательского ввода.
- Подготовка технического отчёта и рекомендаций по защите веб-приложений.

## Результат

В отчёте систематизированы результаты выполнения лабораторных заданий по пяти направлениям веб-безопасности. Для рассмотренных уязвимостей описаны причины возникновения, способы воспроизведения и меры защиты: параметризованные SQL-запросы, контекстное экранирование вывода, серверная проверка прав и бизнес-правил, защита cookie и механизмов входа.

Практическая часть выполнена в лабораторной среде PortSwigger Web Security Academy.
