sublist3r - популярный инструмент на Python для перечисления поддоменов целевого домена.

sublist3r -d domain.com
Опции:
-v — verbose (подробный вывод в реальном времени)
-o — сохранить результаты в файл
-b — перебор по словарю
-t 40 — количество потоков для bruteforce (ускоряет процесс).
-e google, bing, virustotal - указать конкретные поисковые движки/источники.
-p 80,443 — сканировать найденные поддомены на открытые порты
