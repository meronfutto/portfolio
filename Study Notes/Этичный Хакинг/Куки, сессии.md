[[Содержание]]
**Сессия** – это механизм сохранения данных на сервере.

**Куки(cookie)** – набор данных, которые сохраняются в браузере, чтобы сайт помнил пользователя.

**Сессионная кука** – уникальный идентификатор (можем отличить одно от другого) сессии, который позволяет серверу определить пользователя и показать ему разрешённые страницы/данные.

Cookie для злоумышленников:
1. Session Hijacking/Cookie theft: Если злоумышленник знает вашу сессионную куку, он может выдать себя за вас!
2. Межсайтовый скриптинг/XSS (Cross-site scripting) – Это одна из основных техник кража куки. В нек-ых местах на сайте можно вписать JavaScript код, который может выполнять некоторые действия, например: кража сессионной куки.
3. Подмена межсайтовых запросов (CSRF – Cross-Site Request Forgery)
4. Фиксация Сессии (Session Fixation)
