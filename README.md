## Разделы портфолио

### [Операционные системы](./Operating%20Systems/)

Восемь лабораторных и курсовой проект. Работы с Pintos охватывают системный таймер, приоритетное планирование, синхронизацию, передачу аргументов и системные вызовы. Другие темы — разработка CalcOS, обмен данными по TCP/UDP, многопоточные программы и безопасность контейнеризации.

**Технологии:** C, C++, x86 Assembly, Pintos, QEMU, Windows API, POSIX Threads, Docker.

### [Теория вероятностей и математическая статистика](./Probability%20Theory%20and%20Mathematical%20Statistics/course-project-rice-distribution/)

Курсовая работа по распределению Райса. Расчёт описательных статистик, построение эмпирических и теоретических функций распределения, оценивание параметров и моделирование выборок. В отчёте дополнительно разобраны интервальные оценки и статистические гипотезы.

**Инструменты:** Python, Jupyter Notebook, NumPy, SciPy, Matplotlib.

### [Аппаратные средства вычислительной техники](./Computer%20Hardware/)

Четыре лабораторные по ATmega32: архитектура и система команд, цифровой ввод-вывод, таймеры-счётчики, АЦП и ШИМ. Среди практических задач — управление светодиодной гирляндой, работа с EEPROM и таймер обратного отсчёта с семисегментной индикацией.

**Технологии:** AVR Assembly, Atmel Studio, ATmega32.
