# Дмитрий Корпусов

Студент Санкт-Петербургского политехнического университета Петра Великого, направление «Информационная безопасность автоматизированных систем». Интересуюсь безопасностью веб-приложений, тестированием на проникновение и работой SOC.

Здесь собрал свои учебные проекты, лабораторные и курсовые: отчёты, исходники, схемы и результаты работы программ.

## Основные работы

| Работа | Что внутри |
| --- | --- |
| [Практика в Digital Security](Digital%20Security%20Practice/) | Исследование уязвимостей на учебных стендах PortSwigger: аутентификация, контроль доступа, бизнес-логика, SQL-инъекции и XSS. [Отчёт](Digital%20Security%20Practice/report.pdf). |
| [Безопасность контейнеризации](Operating%20Systems/course-project-containerization-security/) | Групповая курсовая по Docker: устройство изоляции контейнеров, разбор уязвимостей и учебные эксперименты. [Отчёт](Operating%20Systems/course-project-containerization-security/report.pdf). |
| [Безопасный подрядчик](Secure%20Contractor/) | Материалы группового проекта стенда для защиты взаимодействия заказчика и подрядчика. В архитектуре используются pfSense, Wazuh и Kali Linux. |
| [Оптимизация игры «Сапёр»](Programming%20Languages/course-project-minesweeper/) | Курсовая на C, выполненная совместно с Иваном Лутониным. Сохранены исходная и оптимизированная версии игры с OpenGL, GLFW и GLEW. |
| [Обращение матрицы на CPU и GPU](Programming%20Languages/lab-03-cuda-matrix-inversion/) | Реализация метода Гаусса — Жордана на C и CUDA, сравнение вычислений на процессоре и видеокарте. |
| [Telegram-бот](Digital%20Analytics/lab-04-telegram-bot/) | Учебный бот на Python и Flask: регистрация, вход и классификация фотографий с помощью модели PyTorch. |
| [Клиенты и серверы TCP/UDP](Operating%20Systems/lab-07-tcp-udp/) | Сетевые программы на C++ для Windows и Linux, исходники и материалы по обмену сообщениями. |

- [Классификация изображений](Digital%20Analytics/lab-03-image-classification/) — обучение ResNet-18 для распознавания человека и животного на фотографии.
- [Работа с расписанием СПбПУ](Digital%20Analytics/lab-02-http-schedule/) — получение и обработка данных через HTTP API.
- [Машина Тьюринга](Mathematical%20Logic/turing-machine/) — модель JFLAP и отчёт с переходами и примерами работы.
- [Распределение Райса](Probability%20Theory%20and%20Mathematical%20Statistics/course-project-rice-distribution/) — анализ выборки, оценка параметров и графики в [Jupyter Notebook](Probability%20Theory%20and%20Mathematical%20Statistics/course-project-rice-distribution/rice-distribution-analysis.ipynb).
