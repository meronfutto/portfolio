# Распределение Райса — исследование выборки

Курсовая работа по дисциплине «Теория вероятностей и математическая статистика». Исследуется выборка из **300 наблюдений**: рассчитываются описательные статистики, оцениваются параметры распределения Райса и сравниваются эмпирическая и теоретические функции распределения.

**Инструменты:** Python · Jupyter Notebook · NumPy · SciPy · Matplotlib

**[Открыть ноутбук](./rice-distribution-analysis.ipynb)** · **[Читать отчёт PDF](./docs/report.pdf)** · **[Отчёт DOCX](./docs/report.docx)**

## Содержание исследования

| Этап | Что рассматривается |
| --- | --- |
| Описательная статистика | Сумма, среднее, медиана, мода, размах, смещённая и исправленная дисперсии, начальные и центральные моменты. |
| Визуализация | Эмпирические функции распределения для выборки и подвыборок, гистограммы, сравнение с теоретической моделью. |
| Распределение Райса | Смысл параметров ν и σ, их влияние на форму функции распределения. |
| Точечное оценивание | Метод моментов и метод максимального правдоподобия с численным поиском параметров. |
| Свойства оценок | Информация Фишера, граница Крамера — Рао и приближённая эффективность оценок метода моментов. |
| Согласие модели с данными | Статистика Колмогорова и разбиение на девять равновероятных интервалов для критерия χ². Полный разбор критериев приведён в отчёте. |
| Моделирование | Генерация отдельной нормальной выборки с параметрами, рассчитанными по исходным данным, методом обратной функции распределения. |

В отчёте дополнительно рассмотрены интервальные оценки, гипотезы о параметрах, сравнение выборок и оценка мощности двухвыборочного критерия методом Монте-Карло. Ноутбук содержит основные расчёты и визуализации; не все разделы отчёта воспроизведены в нём отдельными ячейками.

## Основные выводы

По результатам, приведённым в отчёте, оценки параметров методом моментов и методом максимального правдоподобия оказались близки. Распределение Райса передаёт общую форму выборки, однако при анализе частот в отдельных интервалах обнаружены расхождения.

Модель рассматривается как приближённое описание данных. Близость графиков сама по себе не доказывает соответствие выборки выбранному распределению.

**Особенность проверки согласия:** параметры модели оцениваются по той же выборке. В ноутбуке стандартный порог Колмогорова для полностью заданного распределения используется только как ориентир; для решения на заданном уровне значимости требуется калибровка с учётом оценивания параметров.

## Запуск

Для просмотра сохранённых результатов откройте ноутбук на GitHub или PDF-отчёт. Для повторного выполнения расчётов потребуется локальное окружение Python с Jupyter.

### 1. Установить зависимости

```bash
python -m pip install jupyterlab numpy scipy matplotlib
```

### 2. Указать путь к данным

В первой ячейке с кодом замените:

```python
DATA_FILE = Path("var_6_rice.csv")
```

на путь, соответствующий структуре репозитория:

```python
DATA_FILE = Path("data") / "var_6_rice.csv"
```

### 3. Выполнить ноутбук

Из папки проекта запустите:

```bash
python -m jupyterlab
```

Откройте `rice-distribution-analysis.ipynb` и выполните ячейки последовательно сверху вниз. Рабочая папка ядра должна совпадать с папкой проекта.

Ноутбук создаёт каталог `output/notebook/`, сохраняет в него выбранные графики и сгенерированную нормальную выборку. Для её генерации зафиксировано начальное состояние генератора `42`. Файл в `data/` при этом не перезаписывается.
